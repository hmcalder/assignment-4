# assignment-4
My CSC-372 assignemnt 4 repository

Project Description: 
This projet searches and finds TV shows similar to key words searched by a user. It uses javaScript, HTML, and CSS. This website pulls from TVmaze to find the information displayed. This project caps at 10 shows per search. Each show card displays a description, premiere date, the date it was last updated, the genre, average rating, main cast, and a link to that show on TVmaze. This website also handles empty searches, searches with no matches, and error when pulling from the api. 

Read the official TVmaze API documentation: https://www.tvmaze.com/api
